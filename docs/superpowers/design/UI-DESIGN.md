# Ella 班级管理应用 — UI 设计

状态：待评审　依据：`specs/2026-10-17-infra-and-sync-engine-design.md`、`DESIGN-DECISIONS.md` 四域导航
生成方式：`ui-ux-pro-max` 两次 `--design-system` 检索 + 人工校正。校正项见 §9，未采纳的技能输出不做掩饰。

## 1. 风格基调

采用 **Minimalism / Swiss Style**（检索匹配项，Best For 明确含 enterprise dashboards、professional tools）：
无渐变、无装饰阴影、几何对齐、高对比、栅格驱动。理由：这是高频使用的生产工具，教师每天在里面
停留几十分钟，视觉装饰是负担而非价值。

- 模式：**浅色优先**。检索给的深色方案（`#0F172A` 背景）不采纳——教室光线强、常需投影给学生看，
  深色底在投影和高亮环境下可读性差。深色模式作为可选项保留，但需重新校验对比度。
- 密度：**dense**，间距刻度 `4 / 8 / 12 / 16 / 24 / 32`。表格行高 36px（桌面）/ 48px（触屏）。
- 动效：**subtle**，150–200ms ease，仅用于状态反馈与展开收起；`prefers-reduced-motion` 时直接呈现终态。
  不采纳检索给的 ScrollReveal——工具型应用里滚动进场动画没有意义。

## 2. 布局骨架

不使用任何 landing 模式（Hero / 社会证明 / CTA 分区对内部工具不适用，见 §9）。采用标准应用外壳：

```
┌──────────┬─────────────────────────────────┬──────────┐
│ 侧边导航 │  顶部：面包屑 · 全局搜索 · 同步态 │ 内容区   │
│ 4 域分组 │  ─────────────────────────────── │ (模块)   │
│ 可折叠   │  页面标题 + 域内快捷操作（sticky） │          │
└──────────┴─────────────────────────────────┴──────────┘
```

侧边栏四项分组，组内子页可折叠，当前子页高亮左边框：

| 域 | 子页 |
|---|---|
| 学生 | 档案 · 班委 · 座位表 · 值日 |
| 学业 | 成绩 · 作业 · 学情分析 |
| 日常 | 待办 · 活动 · 行为记录 · 积分排名 |
| 班级 | 课表 · 相册 · 草稿 · 设置 |

移动端（≤768px）折叠为**底部导航**，严格 5 项以内：学生 / 学业 / 日常 / 班级 / 更多（搜索与同步详情进「更多」）。
桌面侧边栏与移动底部导航共用同一份导航配置，不各写一套。

## 3. 颜色语义 token

不写死 hex，组件只用语义变量（`bg-surface`、`text-primary`、`border-subtle`…）。基色板由检索结果
校正而来：以中性石板灰为骨架，teal 作主色，橙作强调与待处理计数。

| 角色 | 用途 |
|---|---|
| `--color-primary` | 主操作、当前导航、焦点环 |
| `--color-accent` | 需要教师注意的计数与提醒（如今日待办数） |
| `--color-success` | 已同步、正向行为记录 |
| `--color-warning` | 待同步、临近截止 |
| `--color-danger` | 违纪、删除、同步失败 |
| `--color-muted` | 次要文本、禁用态 |

约束：正文对比度 ≥ 4.5:1，大号文本 ≥ 3:1；状态**不只靠颜色**传达（见 §6）。

## 4. 字体

- 西文：`Fira Sans`（正文）；标题**不用**检索给的 `Fira Code`——等宽体作大标题在这个场景没有收益，
  标题与正文同源，用字重区分层级（600 标题 / 400 正文 / 500 表头）。
- **中文是主要界面语言**，必须显式声明中文栈：`"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。
  检索结果完全没提中文字形覆盖，这是它的盲区，不能照抄。
- 基础 16px，行高 1.5；表格内数字用 `font-variant-numeric: tabular-nums`，成绩列才能对齐。
- **禁止 CDN 字体**：`@import` Google Fonts 直接违反本地优先原则，且教室里可能加载不到导致首屏文字闪变。
  落地方式：字体子集化后随构建打包（`@fontsource` 自托管或本地 woff2），离线可用。

## 5. 同步状态可视化（本项目独有的必要 UI）

spec §5.1 要求「已保存 ≠ 已同步」分开显示。做成顶栏一枚可点击的状态胶囊：

| 状态 | 表现 | 交互 |
|---|---|---|
| 已保存（刚写入，未推送） | 灰点 + 文字「已保存」 | 无 |
| 待同步 N 条 | 琥珀色 + 计数，轻微脉冲 | 点击展开待推送队列（表名、操作、时间） |
| 已同步 | 绿色 + 「已同步 · HH:mm」 | 点击看上次同步详情 |
| 同步失败 | 红色 + 「重试中 / 需处理」 | 403 类错误必须显示为「需处理」而非静默重试 |
| 离线 / 纯本地模式 | 中性 + 「离线，N 条待同步」 | 明确说明数据已存本地不会丢 |

关键：**绝不出现第三种解释**。写入成功但推送失败时，界面不得同时显示「已保存」和绿色。
状态区用 `aria-live="polite"` 播报变化，不弹窗打断。

## 6. 可达性与触屏

- 触控目标 ≥ 44×44px，间距 ≥ 8px；不依赖 hover 表达唯一信息。
- 焦点环可见且不被 sticky 头部遮挡；模态打开时锁焦点、Esc 关闭、关闭后焦点归还触发元素。
- 键盘优先设计（教师在课上没时间找鼠标）：
  `1–4` 切换四个域、`/` 聚焦全局搜索、`n` 新建域内主实体、`g` 后接首字母进子页、`?` 显示快捷键表。
  搜索框内不拦截单键快捷键。
- 状态不只靠颜色：违纪用红色 + 图标 + 文字，及格用「及格/不及格」文字而非仅绿红底色。
- 表格：`<caption>` 或 `aria-label` 说明内容，表头 `scope="col"`；长名单（44 人）虚拟化渲染。

## 7. 关键模块界面取向

- **座位表**：桌面支持拖拽换座，触屏改为「点选两人→交换」的显式两步（拖拽在小屏上不可靠）。
  拖动时目标格必须有落点高亮；撤销一次换座必须可用。
- **成绩录入**：行内编辑 + Tab 跨列、Enter 换行，这是教师最快的录入路径；单元格即时校验，
  超满分立即就地标红并把错误文字放在该格下方，不用顶部汇总条。粘贴多行需支持。
- **学情分析**：图表按 `chart` 域常识处理——有图例与工具提示，不靠颜色单独区分系列；
  及格线口径由 spec §统一后由数据层提供，UI 不自己算阈值。
- **相册**：本地 blob 优先渲染，未上传的图显示「仅本机」角标，避免教师误以为已同步。
- **待办/活动**：域内快捷新建常驻 sticky，不需要先进子页再找按钮。

## 8. 验收要点（UI 层）

1. 断网时写入，胶囊显示「待同步 N 条」，恢复网络后转「已同步」且计数归零
2. 键盘完成「切换域 → 搜索学生 → 录入一条成绩 → 保存」全链路，无一次必须用鼠标
3. 375px 宽度无横向滚动，底部导航 5 项，触控目标全部 ≥ 44px
4. 浅色正文对比度全部 ≥ 4.5:1；状态信息去除颜色后仍可辨别
5. 首屏在无网络下无字体闪变（自托管字体生效）
