# 设计决定记录

## 2026-10-17 导航结构

侧边栏按四个数据域分组重构，不保留现有 11 个平铺模块入口：

- **学生** — 档案、班委、座位表、值日
- **学业** — 成绩、作业、学情分析
- **日常** — 待办、活动、行为记录、积分排名
- **班级** — 课表、相册、草稿、设置

理由：与 spec 的子项目拆分（「人」「学」「事」「物」四域）保持一致，模块边界与 UI 结构一一对应；
认知负担从 11 个平级入口降为 4 组。已接受的代价：现有使用者（教师本人）的入口位置全部变化，
需要重新适应。

关联文档：`docs/superpowers/specs/2026-10-17-infra-and-sync-engine-design.md`（§11 后续 spec 拆分）。
